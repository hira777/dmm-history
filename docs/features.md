# 機能

## 閲覧履歴の保存

拡張が有効な状態で FANZA の商品ページを開くと、商品の閲覧履歴を保存します。

保存した履歴は拡張のローカルストレージに保存されます。
履歴の最大保存数は 300 件です。
300 件を超えた場合は、新しい履歴を追加するたびに古い履歴から削除します。

## 履歴画面

拡張のポップアップから「履歴を見る」をクリックすると、履歴画面を開けます。

履歴画面では、保存した商品を一覧で確認できます。
履歴は削除と絞り込み検索ができます。

## セール検索フィルター

FANZA の動画検索画面に、セール選択用のプルダウンを追加します。

検索窓からキーワード検索をする時に、選択したセール条件を維持できます。
例えば「すべてのセール」を選んだ状態でキーワード検索すると、検索後もセール対象の商品に絞ったまま検索できます。

セール選択肢は、表示中のページにあるセールリンクから取得します。
固定のセール一覧は持たないため、時期によって変わるセールにも追従しやすくしています。

選択したセール条件は保存されるため、ページを移動しても選択状態を維持します。
ただし、保存済みのセール条件が現在のページに存在しない場合は、自動で「指定なし」に戻します。

検索結果の URL からセール条件が外れた場合も、選択中のセール条件を付け直します。
また、検索結果でプルダウンを変更すると、同じキーワードのまま別のセール条件で再検索できます。
